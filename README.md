# CasualGames

discord.js と JavaScript で作った、メッセージコマンドとスラッシュコマンドで遊べるお手軽ゲームボットです。

## 必要なもの

- Node.js 18 以上
- Discord アプリケーションと Bot トークン

## セットアップ

1. Discord Developer Portal でアプリケーションと Bot を作成します。
2. Bot の **Message Content Intent** を有効にします（`!` 形式のコマンドを使う場合）。
3. Bot をサーバーに招待します。`bot` と `applications.commands` のスコープ、およびメッセージの閲覧・送信権限が必要です。
4. 依存関係をインストールします。

   ```sh
   npm install
   ```

5. `DISCORD_TOKEN` 環境変数に Bot トークンを設定して起動します。

   PowerShell:

   ```powershell
   $env:DISCORD_TOKEN = "ここにBotトークン"
   npm start
   ```

   macOS / Linux:

   ```sh
   DISCORD_TOKEN="ここにBotトークン" npm start
   ```

> トークンはソースコードや公開リポジトリに書かないでください。

## コマンド

起動時にスラッシュコマンドをDiscordへ登録します。初回登録や更新の反映には少し時間がかかる場合があります。

| 種類 | コマンド | 内容 |
| --- | --- | --- |
| メッセージ | `!ヘルプ` | コマンド一覧 |
| メッセージ | `!じゃんけん グー` | ボットとじゃんけん（チョキ・パーも指定可能） |
| メッセージ | `!おみくじ` | おみくじを引く |
| メッセージ | `!数当て` | 1〜100の数字当てゲームを開始 |
| メッセージ | `!数当て 42` | 数字を予想（ゲーム開始から5分間有効） |
| メッセージ | `!コイン` | コインを投げる |
| スラッシュ | `/help` | スラッシュコマンドを含む一覧 |
| スラッシュ | `/janken hand:<グー・チョキ・パー>` | ボットとじゃんけん（`rock`、`scissors`、`paper` も可。例: `/janken hand:グー` または `/janken hand:rock`） |
| スラッシュ | `/omikuji` | おみくじを引く |
| スラッシュ | `/guess start` | 数字当てゲームを開始 |
| スラッシュ | `/guess try number:<1〜100>` | 数字を予想（ゲーム開始から5分間有効） |
| スラッシュ | `/coin` | コインを投げる |

メッセージ形式では、じゃんけんは `!janken` / `!rps`、おみくじは `!omikuji`、数当ては `!guess`、コイン投げは `!coin` / `!coinflip` でも実行できます。  
ゲームの状態やスコアは保存しません（プライバシー重視・軽量設計のため、データの永続化は行っていません）。
